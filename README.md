# 实验报告记录工具 (ExperimentReportTool)

基于 **Qt 6 + C++** 开发的桌面端实验报告记录工具，支持实验项目管理、模板化报告创建、结构化富文本编辑、实验数据表格与图表、多格式导出、元数据检索、打印、版本管理、公式编辑、数据导入、标签管理、附件管理、多用户协作等完整功能。

## 当前版本

**v9.20.0** — 权限分级+工作流+5优化点（四级角色/组实体/提交审核审批/草稿可见性/删除权限/退回意见/待办视图/保存为模板）

## 功能使用指南

### 1. 登录与用户

**登录**
- 启动程序后进入登录界面，输入用户名和密码（账号密码由管理员创建/分配）
- 内置默认超级管理员账号：`admin / admin123`（唯一超级管理员，不可删除，密码登录后可在"工具 → 修改密码"中更改）

**修改密码**
- 菜单：工具 → 修改密码
- 输入旧密码 → 输入新密码（两次确认）→ 确定，下次登录生效

**用户管理**（菜单：工具 → 用户管理，按角色可见可管理的范围）
| 操作 | 说明 |
|------|------|
| 新建用户 | 输入用户名（自动查重，重名会提示），初始密码自动填默认值 `123456`（可修改）；选择角色（超级管理员/总管/组长/组员） |
| 编辑用户 | 修改用户名、密码、角色、所属组 |
| 禁用/启用 | 禁用后该用户无法登录；其名下草稿的删除权自动转移给组长/总管 |
| 删除用户 | 仅超级管理员可删除（总管、组长不可删除用户） |

**谁能管理谁**
- 超级管理员：管理全部用户
- 总管：可管理组长和组员（不可删除用户）
- 组长：可管理本组组员
- 组员：不可管理用户

### 2. 组管理（创建小组/分配组长组员）

- 菜单：工具 → 组管理（超级管理员、总管可操作）
- 创建小组：输入组名 → 指定组长（该用户自动成为组长角色）→ 确定
- 编辑小组：修改组名、更换组长、添加/移出组员
- 删除小组：解散小组（成员回到无组状态）

> 只有先建组、把用户归入组，组员→组长→总管的审核/审批流程才能跑通。

### 3. 四级角色与权限

| 角色 | 报告权限 | 用户管理 | 组管理 | 其他 |
|------|----------|----------|--------|------|
| 超级管理员（唯一） | 全部（查看/编辑/删除/审核/审批/归档） | 全部用户 | 全部 | 数据备份/恢复、审计日志 |
| 总管 | 查看全部、审批（组长审核通过后）、归档、删除禁用用户的草稿 | 组长+组员（不可删除） | 全部 | 数据备份/恢复、审计日志 |
| 组长 | 本组报告审核/退回、查看本组全部报告 | 本组组员 | 本组 | — |
| 组员 | 编写报告、提交审核、撤回、查看本组已提交报告 | — | — | — |

**报告可见性**
- 草稿：仅创建者 + 本组组长可见（总管/超管全部可见）
- 已提交及以上：本组全员可见（跨组不可见）

**编辑权限**
- 草稿：仅创建者可编辑（超级管理员可编辑所有）
- 提交后：仅超级管理员可修改

### 4. 报告工作流

```
草稿 ──提交──▶ 已提交 ──组长审核通过──▶ 已审核 ──总管审批通过──▶ 已审批 ──归档──▶ 已归档
                  │                        │                        │
                  └──撤回──▶ 草稿          └─审核退回─▶ 草稿         └─审批退回─▶ 草稿
```

**各角色操作步骤**
- **组员提交**：编辑完报告 → 菜单"文件 → 提交审核"→ 状态变为"已提交"，进入组长待办
- **组员撤回**：已提交但未审核时 → "文件 → 撤回" → 回到草稿继续修改
- **组长审核**：待办视图点"待审核"标签 → 打开报告 → "文件 → 审核通过"或"审核退回"（**退回必须填写意见**，意见会显示在报告顶部黄色信息栏，供组员参考修改）
- **总管审批**：待办视图点"待审批" → 打开报告 → "文件 → 审批通过"或"审批退回"（退回同样必填意见）
- **总管归档**：已审批的报告 → "文件 → 归档" → 归档后只读锁定，不再修改
- 状态只能通过上述流程流转，编辑器中状态字段只读

**待办视图（报告列表顶部标签）**
- 按钮：全部 / 我的 / 本组 / 待审核 / 待审批
- 打开主界面后自动按角色默认选中：组员→"我的"（含被退回）、组长→"待审核"、总管/超管→"待审批"
- "待审核""待审批"为全局跨项目视图；其余标签在当前项目内筛选

### 5. 项目管理

- 左侧项目树：显示项目及创建者分组（"全部项目 / 某用户的项目"筛选）
- 项目右键菜单：新建项目/子项目、重命名、删除
- 选中项目后，右侧显示该项目下的报告列表
- 项目/报告创建者的项目会默认展开，其他用户的默认折叠

### 6. 报告创建与编辑

**新建报告**
1. 左侧选中项目 → 工具栏"新建报告"（或项目右键）
2. 选择模板（列表仅显示公开模板 + 你自己的私有模板，私有模板标 `[私有]`）
3. 自动打开编辑窗口；**创建者**自动填充且不可修改，**修改者**由系统自动记录

**正文编辑（Word 式连续文档）**
- 正文直接输入文字
- 格式工具栏：字体大小、加粗/斜体/下划线、文字颜色、对齐（左/中/右）、行高（1.0~3.0）
- 格式应用规则：**选中文字**时格式作用于选区；**未选中**时作用于光标所在整个段落
- 工具栏实时回显当前光标处格式（字号/加粗/对齐/行高），随光标移动自动刷新

**插入对象**（工具栏按钮）
| 对象 | 操作 |
|------|------|
| 表格 | 插入表格对象 → **双击**打开编辑器（见第 8 节） |
| 图片 | 插入图片 → 选择本地图片文件 |
| 图表 | 插入图表对象 → **双击**配置（见第 9 节） |
| 公式 | 插入公式对象 → **双击**编辑（见第 10 节） |
| 分割线 | 插入水平分隔线 |

**对象操作**：单击选中（可删除/拖动）、**双击打开编辑**；对象对齐跟随编辑窗设置。

**保存**
- 自动保存：编辑停止 3 秒后自动保存
- 手动：`Ctrl+S` 或菜单"文件 → 保存"
- 只读模式（无编辑权限）：内容不可修改、不可保存

**保存为模板**
- 菜单：文件 → 保存为模板
- 输入模板名称、分类、可见性：组员/组长默认私有，总管/超管可选择公开
- 保存的是当前报告的完整内容快照，之后新建报告可选该模板

### 7. 标签

- 报告编辑窗口顶部：标签下拉框（单选，默认"无标签"）
- 菜单：工具 → 标签管理：新建/重命名/删除标签，可选 12 种颜色
- 报告列表与属性面板中显示带颜色的标签

### 8. 数据表

1. 工具栏"插入表格" → 文档中出现表格对象
2. **双击**表格对象打开数据表编辑器：
   - 动态增删行/列
   - 列属性：名称、类型、单位、必填、取值范围
   - 数据校验（按列属性自动检查）
   - CSV 导入/导出

### 9. 图表

1. 工具栏"插入图表" → **双击**图表对象打开配置对话框
2. 图表类型：折线图 / 柱状图 / 饼图 / 散点图 / 面积图
3. 可配置：标题、坐标轴、图例、网格、主题
4. 数据来源：选择/新建数据表，图表随数据表更新而刷新

### 10. 公式

1. 工具栏"插入公式" → **双击**公式对象
2. LaTeX 语法输入 + 实时预览
3. 内置 20 个常用公式模板（积分、分数、求和、矩阵等）

### 11. 导出

**单份导出**：菜单"文件 → 导出"
- PDF：复用打印渲染，所见即所得
- HTML：网页格式（CSS + 图片内嵌）
- Word：.docx（图片 base64 内嵌，不生成附加文件夹）
- 纯文本：Markdown 风格

**批量导出**
1. 报告列表中按住 `Ctrl`/`Shift` 多选多份报告
2. 工具栏"批量导出" → 选择格式（PDF/HTML/Word/文本）
3. 选择导出目录 → 后台自动逐个导出（显示进度，失败的报告会列出清单）

### 12. 打印

- 菜单：文件 → 打印预览 / 打印 / 页面设置
- 页面设置：A4/Letter、横向/纵向、页边距
- 打印内容按对象实际设置尺寸渲染（表格/图表/图片按实际大小）

### 13. 搜索

- 主界面顶部搜索框输入关键词（标题/内容/标签全文检索，输入停顿自动搜索）
- 支持状态筛选（全部/草稿/已提交/已审核/已审批/已归档）
- 搜索结果列表双击打开对应报告

### 14. 版本管理

- 报告编辑窗口 → 菜单"工具 → 版本历史"
- 操作：保存命名版本、恢复旧版本、删除版本、内容预览
- **版本对比**：在历史版本对话框中选择两个版本 → 并排对比显示
  - 差异颜色标记：删除=红色、新增=绿色、修改=黄色

### 15. 附件管理

- 报告编辑窗口 → 菜单"工具 → 附件管理"
- 操作：批量上传（带进度条）、下载、打开、删除

### 16. 数据导入（CSV）

**标准模板（推荐先导出模板再填写）**
- 数据表编辑器 → 导入对话框 → "导出模板"：按当前表列定义生成模板 CSV（表头含单位 + 合规示例行），保存后弹出填写规则说明（列类型/必填/范围）
- 模板本身是一份合法可导入文件：打开 → 预览 → 导入全部通过

**导入校验（追加/替换模式）**
- 列匹配：按列名对应（文件列顺序可乱）；未知列自动忽略并提示；缺少必填列报错阻止
- 单元格校验：类型（数值/日期/布尔）、必填、数值范围，不合规单元格在预览中**红色标出**
- 存在错误时导入被阻止，需修正后重新预览；"创建新表"模式不做类型校验（列默认文本）

**导入流程**
1. 数据表编辑器 → "导入 CSV" → 选择文件
2. 设置分隔符/编码（自动检测为默认）、首行是否为表头
3. 预览前 20 行确认（含校验标红）
4. 选择模式：追加 / 替换 / 新建
5. 导入（后台解析，大文件不卡界面）

**主窗口"导入数据"**（菜单）：快速导入 CSV 为新建数据表，不做交互校验。

### 17. 模板管理

- 菜单：工具 → 模板管理器：新建/编辑模板（名称、分类、描述、内容）
- 新建报告时选用；模板可见性：公开（所有人可用）/ 私有（仅创建者可用）

### 18. 批量操作

- **批量导出**：见第 11 节
- **批量删除**：报告列表 `Ctrl`/`Shift` 多选 → 工具栏"批量删除" → 系统先做权限过滤（只列出你有删除权的报告）→ 确认后逐个删除
  - 删除权限：创建者/超管可删草稿；创建者账户被禁用后其草稿由组长/总管删除；已提交及以上仅超管可删
  - ⚠️ 删除不可恢复，请谨慎操作（每次删除均记入审计日志）

### 19. 审计日志（仅超级管理员/总管可见）

- 菜单：工具 → 审计日志
- 展示最近 500 条操作记录：时间、操作用户、操作类型、对象、详情
- 覆盖：登录、提交审核/审核通过/审核退回/审批/撤回/归档、删除报告、用户创建/修改/删除、数据备份/恢复
- 带"刷新"按钮实时更新

### 20. 插件管理

- 菜单：帮助 → 插件管理：查看当前已加载的插件及其版本
- 插件以 .dll 形式放在程序目录 plugins/ 下，启动时自动加载（内置示例插件 DemoPlugin）

### 21. 设置

- 菜单：工具 → 设置
- 外观：主题、字体、字号（重启生效）
- 数据：数据库路径（重启生效）
- 颜色实时预览

### 22. 数据备份与恢复（仅超级管理员/总管）

- 菜单：工具 → 数据备份：将当前数据库备份到指定文件
- 菜单：工具 → 数据恢复：从备份文件恢复数据库（恢复前建议先备份当前数据）

### 23. 日志级别控制

- 默认：Release 版输出 `info` 级（Debug 日志编译期屏蔽，零开销）；Debug 构建输出全部
- 现场排查临时开启全量日志（无需重新编译）：
  - 命令行参数：`--log-level=debug`
  - 或环境变量：`ERT_LOG_LEVEL=debug`（命令行优先级更高）
- 可选级别：`debug / info / warning / error`
- 日志文件：程序目录 `logs/`，按大小自动滚动

## 数据库设计

### 数据表清单（11 张 + 1 张 FTS5 虚拟表）

| 表名 | 说明 |
|------|------|
| `users` | 用户表（用户名、密码哈希、角色、所属组、禁用标记） |
| `groups` | 小组表（组长、成员归属） |
| `projects` | 实验项目（树状结构，parent_id 自关联） |
| `reports` | 实验报告（document+objects JSON、创建者、修改者、工作流状态与意见） |

| `templates` | 报告模板（结构含 objects、可见性、创建者） |

## 配置文件说明

`config.ini` 位于程序目录，三节：`[Appearance]`（主题/字体/颜色）、`[Data]`（数据库路径，空则用程序目录 data/）、`[Window]`（尺寸）。均可通过"工具 → 设置"可视化修改，颜色实时预览。

## 开发约定

### 槽函数命名
- 槽函数必须遵循 `on_<objectName>_<signalName>` 命名约定，由 uic 自动连接，禁止手动 connect（示例：`on_m_saveBtn_clicked()`）

### 插件开发
- 继承 `PluginInterface` 抽象基类，`Q_PLUGIN_METADATA` 宏，独立 CMakeLists.txt 编译为 .dll

### 常量管理
- 禁止魔法数字/文字硬编码：外观 → AppTheme、尺寸 → AppDimensions、可配置项 → AppConfig（.ini）、全局常量 → AppConstants
